# Konut Fiyatları Tahmin Projesi

Bu proje, bir makine öğrenmesi modeli (ML) kurmanın tüm aşamalarını kapsamaktadır. Veri kazımadan modelin yayına alınmasına kadar uçtan uca bir ML projesidir. 🚀

Bu proje DeepMineAi kapsamında hazırlanmıştır ve Türkiye’de Streamlit üzerinde ML model deploy edilmesini anlatan ilk Türkçe çalışmalardan biridir.

---

## 📂 Proje Yapısı

Tüm adımlar Jupyter Notebook dosyaları ile sunulmuştur.

[GitHub proje klasörünü görüntüle](https://github.com/GeoVisibility/Yunusmakas-konut-fiyat-tahmin-projesi/tree/main/Proje%20Kodlar%C4%B1)

Not: Dosyaları indirmek için bağlantıya sağ tıklayıp “Bağlantıyı Farklı Kaydet” seçeneğini kullanabilirsiniz.
